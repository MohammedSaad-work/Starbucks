# Starbucks Landing Page

A static, Starbucks-inspired landing page built with HTML and CSS as a front-end practice project.

## Preview

![Starbucks landing page screenshot](Screenshot%202026-11-17%20171833.png)

[View the live demo](https://mohammedsaad-work.github.io/Starbucks/)

## Project overview

The page recreates a coffee brand homepage with a navigation header, promotional banner, image and text panels, call-to-action buttons, and a footer. It uses local image assets and CSS to build the page layout.

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser.
3. Keep `style.css`, `logo.png`, and the image assets beside `index.html`.

The Font Awesome icons load from a CDN, so an internet connection is needed for those icons.

## Technologies

- HTML
- CSS
- Font Awesome (CDN)

## Scope

This is an unofficial learning exercise and is not affiliated with Starbucks. It is a static visual demo; sign-in, ordering, rewards, and footer controls do not provide real functionality. The current layout is desktop-focused and may not display well on smaller screens.
