# Starbucks Landing Page

A static front-end practice project inspired by a coffee-shop landing page. It uses HTML, CSS, and local image assets.

## What it demonstrates

- A navigation header and promotional sections
- Flexbox-based layout and CSS styling
- Use of local images and icon fonts

This is a learning exercise. It is not an official Starbucks website, is not affiliated with Starbucks, and its buttons and links do not provide ordering, sign-in, or rewards functionality.

## Run locally

Open `index.html` in a browser. Keep `style.css` and the image files beside it so the page can load its assets.

## Technologies

- HTML
- CSS
- Static image assets

## Project status

A small static front-end exercise. There is no backend or automated test suite.
